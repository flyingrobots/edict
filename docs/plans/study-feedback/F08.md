## 2. Problem Description

The causal-cell type limits the key to 64 Unicode scalar values. Its target configuration carries a replacement-byte bound but no key bound. Echo does not perform general input-schema validation.

## 2b. Proposed Solution

Define a digest-bound key-bound contract with explicit Unicode units. Make the Echo lowerer, verifier, and invocation path enforce it before mutation. Update the Edict fixture only after compatible Echo support exists.

## 2c. Alternatives considered and rejected

Leave the limitation undocumented: authors cannot identify the contract boundary.
Combine unrelated fixes: a reviewer cannot verify one outcome independently.

## 2d. Acceptance Criteria

Accept a 64-scalar key. Refuse a 65-scalar key before mutation. Cover multibyte keys and raw UTF-8 identity. Test configuration substitution and independent verification. Preserve the old pinned compatibility witness or explicitly version the contract.

## 2e. Test Plan

Golden: a maximum valid key commits. Edges: max+1, four-byte scalars, substituted configuration, and runtime input mutation. Known failure modes: byte/scalar disagreement and changed digest closure. Fuzz and stress: none; deterministic ingress witnesses suffice.
