## 2. Problem Description

Application build wraps CompilerError values in one ApplicationCompilationFailed Debug message. Tools cannot read each compiler kind and source location.

## 2b. Proposed Solution

Emit one edict.cli.diagnostic/v1 record per compiler error. Preserve kind, stage, message, path, and byte span. Add defined line and column coordinates. Preserve deterministic status events and nonzero exit.

## 2c. Alternatives considered and rejected

Leave the limitation undocumented: authors cannot identify the contract boundary.
Combine unrelated fixes: a reviewer cannot verify one outcome independently.

## 2d. Acceptance Criteria

A public build failure exposes each compiler error as fields. Include a file path and line/column. Specify coordinate units. Test multiline and Unicode source. Emit no success artifact after compiler failure.

## 2e. Test Plan

Golden: successful build records remain compatible. Edges: multiple errors, Unicode before the error, multiline source, and an empty span. Known failure modes: incorrect coordinates and partial output publication. Fuzz and stress: none; bounded CLI fixtures suffice.
